# 抠图工艺：AI 白底素材 → 主体 PNG（alpha）

> 本 skill 的铁律：**先处理背景、后落文字**。抠图对象是「主体」——
> 从原图中提取的主要部分（建筑弧墙、人物、器物、地图……），以抠图／剪影形式立于纸面，
> 其余留白给文字。参考例图语法：纹理纸面为场、主体突出、大片空白、小字双语。

## 工艺链

```
原图 ──⓪ 主体被遮挡时：图生图编辑「去除遮挡、补全被遮面」──► 干净原图
     ──① AI 图生图抠取（纯白底）──► cand\*.png（白底素材；三候选各出一版）
     ──② cutout.py（白底→alpha＋去噪＋裁边）──► cut\*.png（透明底主体）
     ──③ auto_compose.py 上纸（背景处理＋自动构图）──► 三版背景拼候选板
         ──Gate：选方向（默认自选并在交付说明理由）
```

## ① 提示词模板（图生图，参考图给原照片）

三候选取「同一主体、不同表现」——全彩抠图／墨色剪影／双色平涂。

**先写「主体描述」（用户初始输入其三）**：一段话描述主体物是什么、什么形态、上下缘如何收束；三套模板的主体名与形态句按此改写。写法规则（实测）：

- 描述成**完整连续的物体**（「一整面弧墙」「一整件器物」），并明说「不是条带、不是碎片，不切割、不分离」；
- **避免字面形状词**（「图带」「条带」「ribbon」）——会被生图工具字面化，主体画成漂浮条带、白隙成孔，识别反而变差；
- 明说**上下缘收束位置**（「上缘为墙顶，下缘沿墙基整齐收束」），让撕口轮廓弧落在主体带内。

实测对照（同素材，白底候选＋cutout.py 亮度键控）：无描述剪影内孔 **10.19%** ／ 字面「图带」**11.31%**（反面）／ 完整连续表述 **6.54%**，且上下缘零接触、撕口弧平滑。案例改写（模板 A 首句）：把「弧形壁画展墙与垂纱帘整体抠出」改为「画面唯一主体物＝照片中间那面**完整、连续的**弧形矿物壁画墙（含表面悬挂的纱帘）——**绝对不是条带、不是碎片；不切割、不分离墙面**；上缘为壁画墙顶，下缘沿墙基处整齐收束」。注意：描述会让剪影更干净，也可能把主体带画得**更扁**——撕纸路线窗口随之变矮，需 `--zoom` 补偿（见 `kraft-tear.md` §4）。

**A 全彩抠图（保留矿物色）**

```
抠图素材生成：把这张展厅照片里的弧形壁画展墙与垂纱帘整体抠出，置于纯白背景。
主体包含左侧土金与青金石蓝矿物纹理的弧形墙、正中蓝绿山水壁画墙、右侧赭红金壁墙，
以及从天花垂下的半透明纱帘；保留壁画真实的矿物颜料色彩与质感，边缘干净利落；
删除黑色天花、灯具、深色地面与镜面反光；主体横向展开、居中放置、四周留白，纯白背景，高清。
```

**B 墨色剪影（皮影／剪纸感）**

```
剪影素材生成：把这张展厅照片中的弧形展墙与垂纱转化为单一深褐色实心剪影（类似皮影与剪纸），
整体为无内部细节的纯色形状，只保留展墙的弧线轮廓与纱帘垂坠起伏的边缘；
置于纯白背景；删除天花、灯具、地面与全部纹理细节；主体居中、四周留白，高清。
```

**C 双色平涂（版画／印刷感）**

```
版画平涂素材生成：把展厅里的弧形展墙提取为一幅双色平涂版画——只用深青金蓝与米白两色，
壁画纹理简化为清晰的两三级台阶式色块，无渐变、无晕染、无光影；
保留弧形墙与垂纱的轮廓结构；置于纯白背景，主体居中、四周留白，高清。
```

**D 去遮挡修复（主体被纱幔／立柱等挡住时，先修原图再抠）**

```
素材修复编辑：删掉这张照片里从天花垂下的半透明纱帘（挡住展墙的其他物件一并去掉），
把被遮住的弧形墙面补全——纹样、颜色与两侧连续自然，光影一致；
展墙造型、矿物色彩与整体构图保持不变；输出纯白背景，高清。
```

提示词要点：① 明说「纯白背景」；② 明说删什么（天花／地面／反光／遮挡物）；③ 明说「不要改变主体造型与颜色」；④ 主体居中、四周留白（便于自动裁边）；⑤ 主体句按用户描述改写为完整连续表述（避免「条带」等字面形状词，见上）。生图有随机性，同题可多跑几版再挑。去遮挡（D）与抠取（A/B/C）分两次执行，不要在编辑里一步到位；敦煌实测：垂帘去除、墙体补全后 `--auto-white` 重抠，得连续完整主体。

## ② alpha 提取（cutout.py）

- 公式：`a = clip((white − L) / (white − floor), 0, 1) ** gamma`，默认 white=255、floor=36、gamma=0.92（实测组合）。
- 去噪：二值化（a>0.28）→ MaxFilter/MinFilter 开闭运算门控小斑点，原 alpha 只保留门内像素（PIL-only，不依赖 scipy）。
- 边缘：`--shrink`（MinFilter 收边，除白边）、`--feather`（高斯柔边，默认 0.8）。
- 裁边：`--trim --pad 16` 裁到主体 bbox 并留透明边。
- 模式：`--mode color` 保留原色｜`--mode ink` 单色剪影（`--ink #2A231A`）｜`--mode duotone` 预设 LUT 平涂＋彩度保留（`--preset 青金`）。

```powershell
python .trae\skills\photo-cutout-forge\scripts\cutout.py --image cand\A2.jpg --out cut\A2.png --mode color --trim --pad 16
python .trae\skills\photo-cutout-forge\scripts\cutout.py --image cand\B.jpg  --out cut\B.png  --mode ink --trim --pad 16
python .trae\skills\photo-cutout-forge\scripts\cutout.py --image cand\C2.jpg --out cut\C2.png --mode color --auto-white --trim --pad 16
```

> 以上为敦煌案例的实际落盘名（生图工具常写 ASCII 文件名）；双色平涂版是米黄底，
> **必须 `--auto-white`**（从边缘条带估背景亮度），否则整底发灰。

## ③ 排障（实测口径）

| 症状 | 处理 |
|---|---|
| 边缘白圈／白边 | 先 `--shrink 1`；仍不净再提高 floor（36→48） |
| 背景残影（灰雾） | 提高 floor；或重生成（强调纯白背景） |
| 小噪声点 | `--despeckle 5`（默认开） |
| 主体被吃掉（浅色纱帘消失） | 降低 floor（36→24）或 gamma（0.92→0.8） |
| 细条纹／薄结构被吃 | 降 `--despeckle`（5→3，或 0 关）——gate 开运算核大于条纹宽度会整条抹掉 |
| 米黄底整底发灰 | 加 `--auto-white`（从边缘条带估背景亮度） |
| 主体不完整／造型被改 | 重生成（强调「不要改变主体造型」） |
| 主体被遮挡物盖住（半透明纱幔／立柱） | 走 ⓪/D：图生图编辑去除遮挡并补全被遮面，再重抠；不要在 alpha 上硬修 |
