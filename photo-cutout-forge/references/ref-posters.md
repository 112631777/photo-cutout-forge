# 参考海报库（assets/ref-posters/）· 排版布局的学习源

> **为什么有这个文件**：老大把 7 张优秀案例**直接放进 skill**——
> 「直接先让你把模板图放入 skill 文件内不是更好学习吗，这样就不会有太大的误差了，
> 也省得我反复跟你强调学习要素」。
> 所以：**落字之前先看图**（`Read` 下面这些文件），不要在脑子里"回忆"它们的风格。

## 0 用法（三步，别跳）

1. **看图**：先 `Read` `_contact-sheet.png`（**10 张**速览）→ 挑 1–2 张与本素材气质相近的，
   再单独 `Read` 那几张原图（看清字号层级与留白关系）。
2. **选招式**：从下面「招式清单」里挑 2–4 招（**不要全上**，参考海报每张只用了 3–4 招）。
3. **落地**：按「落地方式」那列映射到我们的母版与类；
   **字体、画布比例、字号层级不变**（见文末硬约束）。

## 2 招式清单（可复用，按落地成本排序）

> ★ **层级要拉开**（2026-10-11 老大指出）：参考 115 的档位是
> **大标题 ≫ 传播语 > 副题 > 小标签 ≈ 信息**，档与档之间**留出明显跳跃**；
> 而且**大标题本身还分两档**（「敦煌」＞「博物展」）。
> 「字体、海报比例规格不变」不等于「字号层级不敢动」——该拉开的就要拉开，
> 否则整张海报读起来平。落地值见 `calligraphy.md`「当前定稿字号总表 · column 斜向版」。

## 3 附：招式 E 的三条实测（试了三版才定，别再走弯路）
| 试法 | 结果 |
|---|---|
| 死字号 208px ＋ `line-height 0.86` | 文案 1810px 宽 → `overflowX`；行高小于 Inter 的 win 度量 → `overflowY` |
| 容器 `bottom` 取负值让外缘裁切 | 元素盒**越出画布下缘** → 机检在画布外取样 → **P5 = 0、CR 1.14**（看着像"底太暗"，其实越界） |
| **✓ 外层容器 `overflow:hidden` ＋ 内层 span `translateY(28%)`** | 盒留在画布内（实测 (760,1743) 684×132）、字形下半截被规整切掉 ✓ |

配三条参数（照抄）：

```css
--size-giant: 178px;        /* = 版心 1388 ÷ (getlength(文案)/1000)，留 8% 余量 */
/* 字号候选实测：BAMBOO WEAVING 9.934em→139 ／ LANTERN ART 7.213em→192 ／ HORSE & RIDER 7.527em→184 */
.giant { left: 760px; right: 56px; }   /* 字带限制在**纸面区**，别横跨到图上 */
```

⚠ **它是唯一「允许 ovY」的招式**：裁切必然让 `scrollHeight > clientHeight`，
机检会报 `giant(溢出)` —— **这是预期**，改由**目检**把关（下半截被规整切掉、左右顶满）；
若出现 `overflowX` 则说明字号超了，回到公式重算。

## 4 硬约束（老大明确：这些**不变**）

1. **字体不变**：中文标题＝志莽行书（＋艺术字效果）／副题·tagline＝马善政毛笔楷书／
   纯信息层＝sans；英文＝Inter（标题 Black 900）。**不要因为参考海报是别的字体就换字体。**
2. **画布规格不变**：1500 × 1875（比例 0.8）。参考图比例各不相同（1.33–1.80），
   **只学排版关系，不要把它们的画布比例搬过来**。
3. **字号层级不变**：三套双语母版的层级与档位见 `calligraphy.md`「当前定稿字号总表」，
   参考海报的绝对字号不可照抄（那些是干净纸 + 极小灰字的路子）。
4. **信息不删**：主标题／副题／tagline／展期／时间／地点／CTA 一条不少
   （见 `calligraphy.md`「信息完整性」）。
5. **★★ 标题要大、不留白太多**（2026-10-12 老大定）——参考海报多是「干净纸 ＋ 极小灰字」的路子，
   **只学"文字怎么摆"，不要连字号一起学**；口径（上限公式／图像窗 ≥45%／余白比例）见
   `SKILL.md` §〇-6 与 `qa.md` §三-6。

> 一句话：**学的是"文字怎么摆"，不是"用什么字体、多大画布"。**
